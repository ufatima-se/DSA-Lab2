# CS-250 Data Structures & Algorithms

## Lab 02: Dynamic Memory Allocation, Git & Unit Testing

This repository contains my work for **CS-250: Data Structures and Algorithms Lab 02**.

### Topics Covered

* Dynamic Memory Allocation in C++
* Stack vs Heap Memory
* `new` and `delete`
* Dynamic Arrays
* Dynamic 2D Arrays
* Pointers
* Git & GitHub Workflow
* Unit Testing with `assert()`
* Test-Driven Development (TDD)

### Lab Tasks

The repository includes implementations of the following tasks:

1. **Dynamic Salary Program**

   * Uses dynamic memory allocation instead of a static array.
   * Applies the required salary increment formula.

2. **Pointer Analysis**

   * Analyzes memory addresses and values using pointers.
   * Demonstrates both stack and heap allocation.

3. **Dynamic String Reversal**

   * Dynamically allocates memory for a string.
   * Reverses and displays the string.
   * Frees the allocated memory.

4. **Sorted Array Testing**

   * Implements `isSorted()` for checking whether an array is in non-decreasing order.
   * Includes normal, boundary, and edge-case tests using `assert()`.
   * Demonstrates the Test-Driven Development cycle.
